    Advanced options that need extra tools or admin rights
    Tablet as an extra screen Windows needs a virtual display driver for this: the free, open-source Virtual Display Driver (MIT licence, signed by SignPath Foundation). Installing it asks for admin rights once. Then "Extra screen" appears in the tablet's Screen menu.
